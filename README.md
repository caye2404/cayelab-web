# CayeLab — sitio oficial

Web profesional de **CayeLab | Diseñamos oportunidades**.

## Publicación

- `index.html`: sitio estático completo (HTML, CSS y JavaScript integrados).
- `assets/favicon.svg`: icono de marca.
- `assets/compartir.svg`: imagen social en SVG.
- `_headers`: cabeceras de seguridad compatibles con Cloudflare Pages.

Para Cloudflare Pages: conectar el repositorio `caye2404/cayelab-web`, rama `main`, framework **None**, comando de compilación vacío y directorio de salida `/` o la raíz del repositorio según lo permita la interfaz. El sitio no necesita dependencias ni compilación.
